After validating a plugin archive, copy it into `plugins/` and retain the
original in the producing repository's `build/distributions/`. Preserve its
version and variant filename, including comparison builds such as UP-008;
all variants belong directly in `plugins/`, without an alternatives subfolder.
This gives IntelliJ's **Install Plugin from Disk** action one directory for FDE,
EmmyLua2 and LSP4IJ. Keep build logs and test evidence in the repository build
directories rather than alongside the installable ZIPs.

EmmyLua2 build and routing-test logs similarly live in its own `build/logs/`.
Its prepared distribution is generated by `scripts/build-module-patch.sh`;
rebuild it after cleaning that repository's `build/` directory. There is no
second EmmyLua2 dependency installation under `dev/plugins/` (the isolated IDE
has its own installed copy, as required to run it).

`./gradlew test buildPlugin` is the native build entry point. Gradle checks
source pins and the EmmyLua routing hook, installs locked npm dependencies,
builds the toolkit and generates/bundles notices when needed. All local dependency
paths have defaults; `-PideaPath`, `-Plsp4ijPath`, `-PemmyPath` and `-PtoolkitPath`
override them. `clean`, `help` and `tasks` do not prepare external dependencies.

The optional `bash scripts/build.sh ...` wrapper selects the isolated shared
cache/home/temp directories and JDK, captures output, and delegates to Gradle.
Direct Gradle invocations use normal Gradle/JVM environment settings; use
`GRADLE_USER_HOME=$WORKSPACE/dev/cache/gradle` for the shared cache. The wrapper's
log is removed if its command cleans `build/`; native console output is unaffected.
`-PplatformTests` selects real-process platform tests with temporary mod projects
in `build/test-work/platform/`; `-PrealMods=/path/to/mods` tests copies of real mods.

With the isolated IDE closed, run `python3 scripts/prepare-test-ide.py` and then
`bash scripts/launch-test-ide.sh`. Preparation retains local preferences/licensing
in `dev/ide`; it no longer copies anything from historical IDE profiles. The
launcher derives the workspace path and honors `FMTK_IDEA_PATH`.

Protocol scripts create `build/test-work/protocol/fixture` from the seed if absent,
rewrite its absolute configuration paths, and keep logs/evidence/runtime writes
in that disposable tree. `FACTORIO_TEST_ROOT` overrides the test-work root.
Delete its `fixture/` directory to reset it from the reusable seed.

The `dev/` tree contains local-only resources and licensing/preferences. It must
not be committed. Repository-local `build/` directories are already ignored.
The migration did not delete old spike evidence, the old `spike/emmy-target/`,
or the historical `spike/ide/`; it copied LSP4IJ and reusable protocol/module
inputs from those historical locations. Historical acceptance notes retain their
original paths and describe the old layout.

Workspace-report file checks use the project's cancellable read-action helper. Closed-file diagnostics and their
error status are published together through one immutable snapshot. Workspace
reports honor synchronous/asynchronous DocumentMatchers without connecting
documents or starting servers. Pending matchers leave lifecycle operations
unblocked, failed matches reject only their report, and provider removal clears
its cached diagnostics while preserving open-file results owned by an active
document provider with the same identifier. Cache replacement restarts only
providers with affected result IDs or a matching pending file. Other requests
continue, filtering stale reports for replaced caches until their next pull.
Repeated changes to the same cache replace its URI-keyed filter, keeping
long-lived requests from accumulating duplicate predicates. Upstream's updated
build tools and document lifecycle fixes are retained.
Empty reports retain result IDs without allocating caches for uncached, unopened
files. A file that stops matching clears
only its provider diagnostics; other files/providers and open-document reports
are retained. The package version preserves upstream `-SNAPSHOT` and appends the
separate `pluginBuild` counter. Its checkout is
`upstream/lsp4ij/build/checkouts/patched`; the contribution checkout is
`upstream/lsp4ij/build/checkouts/dap-executor-routing`. FDE **0.9.2-dev** contains
the native Lua profiling feature and is built against this dependency.

Run `intellij-factorio/scripts/build-lsp4ij.sh` to prepare the pinned archive.
For a local build, `lsp4ij.lock` records the version, source revision and SHA-256;
the script requires that revision and a clean tracked source tree before building
an absent archive. It also supports official archives pinned by URL and SHA-256.
Both paths verify the hash, plugin ID and version before replacing
`dev/plugins/lsp4ij`. Gradle checks its `artifact.lock` against the repository pin.
Archives remain in `upstream/lsp4ij/build/distributions/`. Preparation does not
change the regular IDE profile.
